# Setup Guide

This document explains how to run Vehicle Diagnostic UI Demo locally.

## Installation

Install dependencies:

```bash
npm install
```

## Run Locally

Start the Vite development server:

```bash
npm run dev
```

Open:

```text
http://localhost:5174
```

If Vite starts on a different port, use the port shown in the terminal.

## Build Check

Run:

```bash
npm run build
```

This checks that the React, TypeScript, and Vite frontend builds successfully.

## Development Notes

This is a frontend-only dashboard demo.

It currently uses mock vehicle diagnostic data rather than a backend API or real vehicle data source.
