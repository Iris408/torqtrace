# Learning Notes

This document explains what TorqTrace demonstrates.

TorqTrace started as a smaller React / TypeScript vehicle diagnostic dashboard and was later remodelled into a WordPress frontend dashboard concept. The v1.0.0 release focuses on WordPress theme structure, responsive UI design, and polished dashboard presentation.

## Skills Practiced

Through this project, I practiced:

- WordPress theme file structure
- PHP template composition
- WordPress `front-page.php` usage
- WordPress `functions.php` setup
- Enqueuing theme styles
- HTML dashboard structure
- CSS dashboard styling
- Responsive UI layout
- Mobile-first correction and polish
- Dashboard card design
- Technical interface styling
- Screenshot-ready portfolio presentation
- Automotive-adjacent product thinking

## WordPress Concepts

This project demonstrates:

- Creating a custom WordPress theme
- Using `style.css` for theme metadata
- Using `functions.php` for theme setup
- Enqueuing styles through WordPress
- Creating a custom homepage with `front-page.php`
- Splitting shared layout into `header.php` and `footer.php`
- Providing a fallback template through `index.php`
- Building a static WordPress frontend concept without relying on the block editor

## Frontend Concepts

This project demonstrates:

- Building a dashboard-style interface
- Creating metric cards
- Creating status badges
- Creating a diagnostic table
- Structuring sidebar cards
- Managing responsive layouts
- Handling mobile table scrolling
- Preventing mobile overflow properly
- Designing for desktop, tablet, and mobile screenshots
- Balancing visual polish with simple maintainable CSS

## What Changed From the Earlier Version

The earlier version was a React / TypeScript / Vite frontend dashboard demo.

The v1.0.0 WordPress version changes the project direction by:

- Moving the active project into a WordPress theme
- Rebuilding the dashboard as a static WordPress homepage
- Improving the visual presentation
- Improving screenshot readiness
- Adding stronger responsive behaviour
- Archiving the old React / TypeScript / Vite implementation for reference
