Through this project, I practiced:

- React frontend development
- TypeScript component structure
- Vite project setup
- CSS dashboard styling
- Responsive UI layout
- Mock data modelling
- Filtering UI state
- Selected item state
- Dashboard card design

- Technical product thinking for automotive diagnostics

## Frontend Concepts

This project demonstrates:

- Rendering lists from data
- Filtering items by severity
- Showing selected item details
- Separating overview information from detail panels
- Displaying status information visually
- Building a dashboard-style interface
- Designing a technician-focused workflow

- Technician action guidance
- Alert severity prioritisation
- Recent diagnostic event history
